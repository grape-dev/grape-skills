# 博客需求引导与需求清单指南

> 配套 `skills/vod/feedback-loop/blog-vod/SKILL.md`。覆盖：三轮收敛问卷示例、确认提示、博客需求清单 JSON 模板与默认值规则。

## 一、三轮收敛问卷

逐轮递进收敛，每轮只问 2-4 个问题，不一次性抛太多。

### 第一轮：大方向确认

| 维度 | 引导提问 | 判断标准 |
|------|---------|---------|
| 主题聚焦 | 文章围绕哪个具体产品或概念展开？侧重什么角度？ | 主题描述包含具体对象 + 角度 |
| 参考风格 | 有想模仿的文章/博客链接吗？或想要什么风格（科技评测/轻松科普/营销推广）？ | 有 URL 或风格描述 |
| 标签分类 | 这篇文章归到哪个分类？（现有标签：1=技术、2=生活、3=随笔、4=教程，也可新建） | 明确分类名称 |

提问示例（评论 body 前缀 `[blog-vod Agent]`）：

```
[blog-vod Agent] 收到博客需求，先确认几个方向：
- 主题聚焦：您提到「华为问界汽车」，想从哪个角度切入？
  是产品横评（M5 vs M7 vs M9）、技术解析（ADS 智驾/鸿蒙座舱），还是用户体验分享？
- 参考风格：有没有想模仿的文章链接？或想要什么风格？
- 标签分类：这篇文章发到博客的哪个分类？
```

### 第二轮：内容细节

| 维度 | 引导提问 | 判断标准 |
|------|---------|---------|
| 文章结构 | 希望分几个章节？需要用表格做参数对比、或引用块突出亮点吗？ | 章节数量 + 特殊元素偏好 |
| 配图风格 | 配图偏实拍风格还是概念插画风？封面图有什么视觉要求？ | 风格描述 + 配图张数 |
| 视频方向 | 文章开头的 5 秒视频想展示什么画面？旁白文案写几句？ | 画面构想 + 语气 |

提问示例：

```
[blog-vod Agent] 方向已明确，继续深入细节：
- 主题聚焦：华为问界汽车的产品定位与技术亮点
- 参考风格：科技评测风，深度技术分析 + 参数对比
- 标签分类：2（生活）/ 或新建「汽车」
- 待补充：文章结构（几章、是否需要对比表格）？
  配图风格（写实产品风还是概念科技风）？封面图要求？
  开头 5 秒视频画面构想与旁白语调？
```

### 第三轮：边界确认（如有需要）

| 维度 | 引导提问 | 判断标准 |
|------|---------|---------|
| 文章长度 | 大概多少字？约 1000-1500 字（标准）还是 1500-2500 字（深度）？ | 字数区间 |
| 文章语调 | 行文语气偏技术深度、专业严谨、还是轻松易懂？ | 语气描述 |

提问示例：

```
[blog-vod Agent] 细节基本完整，最后确认两个边界：
- 文章长度：标准（约 1200 字）还是深度（约 2000 字）？
- 语调偏好：偏技术参数分析，还是偏用户体验描述？
```

## 二、确认提示（写操作前置确认）

输出需求清单后，必须等待用户确认后方可执行写操作（标签创建、评论发布、A2A 交办）。

```
[blog-vod Agent] 需求清单已生成。请确认是否执行以下写操作：
1. 给 Issue 添加标签：blog-vod, type:feature
2. 发布需求确认评论
3. A2A 交办 Issue Agent
回复「确认」继续，或修改需求后重新确认。
```

- 用户回复「确认」或等同意思：继续执行收尾动作
- 用户提出修改：回到对应轮次重新收敛，重新输出，重新输出需求清单
- 用户明确拒绝：结束流程，不执行任何写操作

## 四、默认值与续跑规则

1. 用户在某轮次未回复的维度，用合理默认值填充并在清单中标注「默认值」：
   - 文章长度未确认：默认「标准（约 1200 字）」
   - 配图未确认：默认 3-5 张写实产品风
   - 视频未确认：默认 5 秒产品展示画面 + 专业介绍语调
2. 每轮收敛后，把已确认的维度（增量）追加写入 Issue 评论的需求清单，作为会话续跑依据。
3. 会话中断重启后，先读取 Issue 评论中的需求清单恢复已收敛轮次，不重复提问已确认项。
