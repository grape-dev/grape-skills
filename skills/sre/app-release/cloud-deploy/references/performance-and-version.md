# Cloud Deploy — 性能预算 / 版本管理 / 可靠性声明

> 本文档为 cloud-deploy 技能的运行时预算、演进策略与可靠性声明细节。SKILL.md 的 `## 步骤 / Steps`（§1~§6）与 `## 判断标准 / Verification` 章节为其流程与验收摘要，本文档补充运行时量化基线与演进归档。历史实操教训按时间线归档于本文档 §2「演进时间线」，不另设章节。

## 1. 性能预算

| 指标 | 基线 | 说明 |
|------|------|------|
| LLM 调用次数 | 1-3 次 | 单次部署 = ①入口判定/操作类型识别 ②流程执行（§1-§4）③验证与回帖；资源释放流程同类 |
| token 消耗 | 9K-11K token | SKILL.md + references（contracts / performance-and-version）合计；加载即用，无冗余上下文 |
| 加载时延 | < 1s | 3 个文件 / 约 33KB，无脚本依赖 |
| 单次执行时延（P95） | ≤ 600s | 受任务超时上限约束；分段基线见 1.1 |

### 1.1 分段时延基线（hcloud 安装 / ECS 创建 / pip 安装 / SSH 部署 / 验证）

| 阶段 | 基线 | 约束 / 超时 |
|------|------|-------------|
| hcloud 安装（首次，worker 缺失时） | 60-180s | 下载 `--max-time 300`；arm64 OBS 下载曾 90s+，给足上限；`gzip -t` 校验完整性 |
| ECS 幂等复用检查 | < 10s | 已存在同名 deploy-<repo> 实例则直接复用，跳过创建段 |
| ECS 创建（首次） | 30-120s | 动态选最小可用按量规格；带 keypair；创建后轮询浮动 IP |
| 代码上传 + SSH 部署 | 60-180s | 单条 SSH 会话跑完（简化版依赖安装 + 启动），防止多会话叠加超时 |
| pip 依赖安装 | 30-180s | 华为云 PyPI 镜像优先，失败回退官方源重试 3 次，每次间隔 5s |
| 验证（HTTP / 端口） | < 10s | `curl` 状态码探测 + `ss` 端口监听检查 |

### 1.2 上下文压缩策略

- 大段实测教训与细节沉淀在 references/ 归档，SKILL.md 仅保留摘要、表格与指引，控制加载 token。
- 执行时按需读取 references 相关小节，不整体载入；回帖仅输出结论摘要与 JSON 块。
- 如 SKILL.md 持续增长，将更多示例代码块拆往 references/。

## 3. 可靠性声明

| 机制 | 声明 |
|------|------|
| 断点续跑（resume） | 中断后重跑安全：①ECS 幂等复用检查复用已建实例，绝不重复创建（`deploy-guide.md` §3.1）；②venv 重建 + pip 重试幂等；③部署步骤可重复执行，无累积副作用 |
| 重试幂等 | ECS 按名称前缀复用、资源释放幂等（资源已不存在视为成功）、task profile 由 `trap ... EXIT` 清理，重试不产生重复资源/凭据残留 |
| 资源清理 | `trap` 删除 `task-$$` profile；obsutil 用 `-i/-k` 直接传 AK/SK，不写全局 `.obsutilconfig`；部署失败输出错误信息、不自动回滚；释放流程逐个查询验证已删除 |
| 降级策略 | hcloud 缺失自动安装（架构自适应）；pip 镜像失败回退官方源重试 3 次；apt/pip/npm/docker 镜像优先、镜像不可用才回退官方源；hcloud 命令差异以 `--help` 实测自适应；网络不可用如实报告用户，不绕行 |

## 4. 与检查规范的映射

- 「单次执行时延」：分段基线 + P95 ≤ 600s 声明，外部调用均有界（`--max-time`、重试次数、单会话）。
- 「LLM 调用次数」：1-3 次预算与阶段拆分说明。
- 「token 消耗」：9K-11K 基线 + 上下文压缩策略。
- 「Schema 演进」：版本管理策略、演进时间线与归档位置。
- 「长时任务稳定」：断点续跑（resume）机制、超时与重试边界。
