# 领域 Swarm 二次开发场景

基于 jiuwenswarm 模板仓库二次开发完整领域化 swarm（前端功能页 + 后端 RPC/REST 落库 + 领域 Agent + 品牌改造），产出即用的领域化多 Agent 协作系统。

## 技能链路

1. **VOD** — 领域需求引导（domain-vod）
2. **Issue** — 领域 Spec 设计（domain-issue）
3. **Coding** — 领域二次开发实施（domain-coding）
4. **QA** — 领域验收测试（domain-qa）
5. **SRE** — 华为云部署（domain-deploy）

## 推荐模板

jiuwenswarm-develop — swarm骨架

## 适用场景

- 法务、财务等领域化 swarm 二次开发
